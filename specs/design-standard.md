## 3. 空白页水印

- 来源：**对应分区的 SF 图标组件实例**（禁止手绘/拷贝画板）
- 尺寸：外框 80×80，**内容（字形）必须精确 80×80**，子级位于 (0,0)
- 位置：@ (547,308)（内容区视觉中心）
- 颜色：`#FFFFFF`，图层不透明度 **0.06**
- 命名：`水印 · <分区名>`

## 4. 图标组件体系

- 主本：图标库内 16×16 画板，命名 `SF / <图标名> 16px`；组件名 = 图标名（无前后缀）
- 帧内实例：命名 `SF / <图标名>`；水印实例命名 `水印 · <分区名>`
- **一切图标用组件实例，禁止复制画板**（拷贝会使主本修改不联动，字形修复会丢失）
- **所有图标不分大小一律取自 SF 组件库**——禁止临时椭圆、◌ 字形、手画替代物
- 现有 15 个组件：收件箱、今天、计划、随时、以后再说、日志簿、废纸篓、
  待办圆圈、新建待办、跳转、搜索、筛选、圆圈、虚线圈、备注
- 图标库布局：每个单元 = 16px 主本 @ 格子左上 + 48px 实例 @ (x+27, y) + 标注文字；
  板高随内容自适应（新增行时同步扩高背景）
- 待办圆圈 = 列表/项目行圆圈；圆圈 = 项目图标；虚线圈 = 某天未确认态（点阵环实现——
  插件 `strokeDashPattern` 会被异步回滚，不可用）
- **备注指示 = `SF / 备注`（页形+横线）**：待办有备注时显示于标题/徽章右侧约 10px，
  尺寸 8×11～11×11；**禁止空矩形/豆腐块占位**
- **虚线勾选框（SF/虚线圈）规格：16×16，图形点阵环在框内上下左右居中，与同行文字垂直中心对齐**；
  仅页面标题图标放大到 22×22
- 某天项目组头 = `SF / 以后再说` 图标 + "以后再说" 15px 白字（下划线）

### ⚠ 实例缩放操作（踩坑记录）

- `instance()` 创建后内容尺寸**异步稳定**，刚创建时读数不可信
- 实例根 `resize(S,S)` 只按框比例缩放内容，**不等比铺满**
- 正确做法（收敛公式）：
  1. `inst.resize(S, S)` 设外框
  2. `inst.children[0].resize(S, S)` + `setParentXY(children[0], 0, 0)` 让内容精确填满
- 递归缩放群组+子级会双重缩放（群组 resize 已带动内容），禁止

## 6. 机器校验清单

改动设计稿后执行（Penpot MCP `execute_code`），全部通过才算完成：

| # | 断言 | 容差 |
|---|---|---|
| 1 | 每帧侧栏 8 个图标：x≈16、16×16、|图标中心−文字中心| | ≤ 0.6px |
| 2 | 每帧标题图标 22×22 @ (301,69)；底栏 5 个图标位置同 §2 | ±1px |
| 3 | 空白帧水印：外框 80×80 @ (547,308)、内容 80×80、opacity 0.06、白填充 | 0px |
| 4 | 帧内 `SF /` 形状全部为组件实例（`component()` 非 null） | — |
| 5 | 图标库：全部主本（现 15 个）均有对应 48px 展示实例，背景板随内容自适应，无杂散画板 | — |
| 6 | 配色抽检：侧栏矩形 `#2D3031`、画板 `#2B2D2D` | — |
| 7 | 页面顶层无游离元素（Root 子级 = 18 个画板，无其他类型） | — |

校验脚本模板（按断言逐项输出 PASS/FAIL，保持单次调用数据量小、分批执行）：

```js
// 断言1：侧栏对齐（逐帧）
const f = penpot.currentPage.root.children.find(c => c.name === '主框架 · 今天');
const texts = f.children.filter(c => c.type === 'text' && c.parentX > 35 && c.parentX < 45 && c.height >= 14 && c.height <= 17);
for (const ic of f.children.filter(c => c.name.startsWith('SF /') && Math.abs(c.parentX - 16) < 3 && Math.round(c.width) === 16)) {
  const bd = Math.min(...texts.map(t => Math.abs((t.parentY + t.height / 2) - (ic.parentY + ic.height / 2))));
  if (bd > 0.6) console.log('FAIL align', ic.name, bd.toFixed(1));
}
```
